=== ОТЧЁТ ПО ДЕФЕКТАМ КЛАССА StringUtils ===

1. Метод capitalize()
   - Описание: Метод делает первую букву заглавной, а все остальные буквы приводит к нижнему регистру.
   - Ожидаемое поведение по документации: только первая буква заглавная, остальные остаются как есть.
   - Пример: передаём "skyPro", получаем "Skypro", а ожидаем "SkyPro".
   - Серьёзность: средняя (не критично, но не соответствует описанию).

2. Метод trim()
   - Описание: Удаляет только обычные пробелы, но не удаляет табуляции, переводы строк и другие пробельные символы.
   - Ожидаемое поведение: удалять любые пробельные символы в начале.
   - Это может быть допустимым, если под "пробелами" подразумеваются только ' '.
   - Однако в документации не уточнено, поэтому стоит обратить внимание.

3. Метод contains()
   - Описание: Не обрабатывает аргумент None.
   - При передаче None в качестве строки или символа метод выбрасывает исключение.
   - Ожидаемое поведение: либо возвращать False, либо явно обрабатывать None.

4. Метод delete_symbol()
   - Описание: Аналогично, не обрабатывает None.
   - При передаче None в качестве строки или символа метод выбрасывает исключение.

=== БАГ-РЕПОРТ ===
Метод: contains()
Описание: При передаче пустой строки ("") в качестве искомого символа метод возвращает True,
хотя по документации ожидается поиск символа, а не пустой строки.
Шаги воспроизведения:
1. Вызвать contains("abc", "")
2. Метод возвращает True
Ожидаемый результат: False
Фактический результат: True
Серьёзность: низкая
